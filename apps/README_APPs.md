Browser apps to preselect the  sequences

to run the in the background, 
1. open CLI,
2. open a new screen (apt-get install screen if not available, screen -S runapp)
3. navigate to the directory where app.py is and type :

´flask run --host=0.0.0.0 --port=5000´

(for the other app use 5001)
 
4. exit screen (ctral+a+d) to run in background
